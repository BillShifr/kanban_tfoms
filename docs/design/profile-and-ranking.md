# Профиль и рейтинг

Профиль разделён на личные данные и коллекцию достижений. Черновик формы
сохраняется при переключении вкладок; закрытие несохранённого профиля
по-прежнему требует подтверждения. Загрузка фото сохраняется отдельно.

На desktop слева расположены идентичность и фото, справа — поля с одинаковым
ритмом отступов. Фамилия и имя образуют пару. На телефоне блоки и поля
выстраиваются в одну колонку. Ошибка и подтверждение находятся рядом с сохранением.

## Новый визуальный язык геймификации

После пересмотра владельцем прежнего решения рассмотрены три направления:

| Направление       | Типографика и композиция                              | Решение                                                                                          |
| ----------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Спортивное табло  | Узкие Barlow, крупные номера, жёсткая таблица         | Отклонено: в узкой панели дробит информацию и зажимает имя                                       |
| Игровая коллекция | Округлые Nunito, яркие отдельные плитки               | Отклонено: слишком много конкурирующих подложек для рабочего продукта                            |
| Сезонная карточка | Геометричный Manrope, чернильный фон, мятный прогресс | Выбрано: одна типографическая система для кириллицы и чисел, отдельный характер без игрушечности |

Раздел имеет собственную палитру в обеих темах, не меняя остальной канбан:
фон #111d2f, основной текст #f3f6ff, вторичный #a9b6ca,
мятный #bcf5df для личного прогресса и золото #f3d99c для первых трёх мест.
Manrope 400–800 включён локально с лицензией SIL OFL.

Иерархия панели: месяц → область рейтинга → личный результат → ближайшее
достижение с реальным прогрессом → лидеры → переход к полной коллекции.
Узкая панель не повторяет широкую таблицу: три колонки, без аватаров,
имя в одну строку с многоточием и полным текстом в title.
В полном рейтинге на desktop аватары остаются; на телефоне приоритет у имени.
«Вы» — компактная подпись, а не цветная заливка всей строки.
Место и баллы подписаны в заголовке; единицы каждой строки доступны
скринридеру, но визуально не повторяются.

Места и баллы остаются без подложек и рамок. Слабый статичный золотистый
ореол только вокруг цифр выделяет места 1–3 и их баллы.
У остальных цифры жирные, без свечения.
Акцент не означает присуждения сезонной
награды. Рамки и аура по-прежнему определяются сохранёнными результатами сезона.
Иллюстрации достижений и правила начисления не изменены.

Локальный навык проекта: `kanban-product-design` в пользовательском каталоге
Codex skills. Он ограничен этим продуктом и не меняет правила других проектов.

Основа решений: [размер полей GOV.UK](https://design-system.service.gov.uk/components/text-input/)
и [поведение модальных окон W3C](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).
Источники используются для поведения и доступности, а не как визуальный шаблон.
Для новой композиции рассмотрен принцип отдельной выразительной типографики
из [Duolingo](https://design.duolingo.com/identity/typography);
брендовые шрифты, персонажи и оформление Duolingo не копируются.
