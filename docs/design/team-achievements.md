# Команда и достижения — пересборка интерфейса

## Проблема и принцип

Предыдущая версия добавляла в шапку две конкурирующие кнопки, прятала
геймификацию в Drawer и смешивала месячные баллы с накопительными счётчиками.
Новая версия — вспомогательная постоянная панель, а не второй центр управления.
Основная работа остаётся на доске. Профиль находится в правом меню пользователя.

## Основания решений

- [Primer: layout](https://primer.style/product/getting-started/foundations/layout/):
  основная область для работы, правая — для дополнительного контекста.
- [Primer: PageLayout](https://primer.style/product/components/page-layout/):
  отдельная панель и адаптация к узким экранам вместо сжатия основного содержания.
- [GitHub: profile reference](https://docs.github.com/en/account-and-profile/reference/profile-reference):
  достижения объясняют конкретные действия; приватные источники не раскрываются.
- [GitLab: achievements](https://docs.gitlab.com/user/profile/achievements/):
  различаются постоянные и отзывные награды. Здесь выбран явно объяснённый
  пересчитываемый прогресс; ручное награждение и публичные профили не добавляются.
- [Исследование GitHub achievements](https://arxiv.org/abs/2303.14702):
  значки не являются доказательством качества работы. Рейтинг не используется
  как оценка сотрудников, отсутствуют штрафы за отсутствие ежедневной активности.

Это основания проектных решений, а не заявление о копировании GitHub.

## Компоновка

- Шапка 56 px: бренд слева, единственное меню пользователя справа.
- На широком экране: навигация / доска / закреплённая панель 288 px.
  Доска сохраняет горизонтальную прокрутку колонок. Панель не перекрывает карточки.
- На экранах до 1100 px: постоянная компактная полоса внизу с личными баллами
  и входом в достижения. Полная панель открывается по явному действию.
  На телефоне не создаём второй ряд кнопок в шапке.
- Счётчики колонок — крупные табличные цифры на нейтральном фоне с разделителем,
  не синие круги. Состояние и число — разные визуальные сущности.
- Иллюстрации наград — оригинальные коллекционные эмалевые значки.
  Недостигнутые остаются узнаваемыми, статус указан текстом, не только цветом.
- В карточке автор и исполнитель находятся в отдельной строке;
  метки остаются самостоятельной группой.

## Сценарии и состояния

| Сценарий                    | Поведение                                                                          |
| --------------------------- | ---------------------------------------------------------------------------------- |
| Первый вход без событий     | 0 баллов, объяснение первого действия, никаких выдуманных наград                   |
| Выбор области               | Доступные доски / все сотрудники; область указана рядом с результатом              |
| Общий рейтинг               | Только агрегаты сотрудников, без названий, ссылок и ID закрытых задач              |
| Пользователь не в первых 20 | Личная позиция показана отдельно, список явно подписан «первые 20»                 |
| Равные баллы                | Одинаковое место; порядок внутри ничьей не означает превосходства                  |
| Просмотр награды            | Нажатие раскрывает условие, текущий прогресс и правила пересчёта                   |
| Ошибка загрузки             | Ошибка и повтор, не ложный ноль; при устаревших данных явно сообщаем об этом       |
| Открытие профиля            | Из правого меню; сохранение, отмена, подтверждение несохранённых изменений         |
| Фото                        | PNG/JPEG/WebP, нормализация размера, понятная ошибка; удаление отдельным действием |

## Контракт баллов (сохранён, без изменения миграций)

- Создание: 2 балла автору; первое завершение: 10 назначенному пользователю.
- Завершение означает перенос в последнюю колонку. Без назначенной учётной
  записи баллы за завершение не выдаются.
- Повторное закрытие не создаёт новое событие. Возврат в работу временно
  исключает баллы завершения; повторное закрытие возвращает исходное событие
  в его исходный месяц, а не начисляет баллы за текущий.
- Смена исполнителя после закрытия не переносит уже записанные баллы.
- Удаление задачи удаляет её события. Архив доски исключается из рейтинга;
  восстановление возвращает события. Архивирование учётной записи исключает
  её из списка участников.
- Область «доступные доски» учитывает действующие права. Изменение доступа
  может менять показатели. Администраторы видят все доски.
- Месячный период — UTC. Накопительные условия значков считаются отдельно,
  за всё время учёта в выбранной области. Это текущие достижения, не
  необратимые награды: отмена результата может изменить статус.
- Исторические создания до включения учёта не восстановлены. Нельзя обещать
  пользователю полный стаж или рейтинг за прошлые месяцы.
- Никаких баллов за комментарии: не поощряем шум. Никаких ежедневных серий,
  искусственного дефицита, рейтинга «худших» и наград за сверхурочную работу.

## Проверка

Обязательны реальный API и браузер: обе области, приватность, нулевое состояние,
профиль и фото, условия наград, мобильная полоса, отсутствие перекрытия доски,
светлая/тёмная темы, полная регрессия карточек и drag-and-drop.
CI: format, typecheck, eslint, unit, production build, PostgreSQL integration,
desktop/mobile Playwright. Миграции этим редизайном не изменяются.

## Иллюстрации

Созданы встроенным imagegen, не скопированы с GitHub. Общая постановка:
original collectible enamel achievement pin, transparent background, no text,
silver sculpted rim, layered saturated enamel, readable at 80 px.
Сюжеты: coral paper airplane / emerald lighthouse / violet bridge / golden summit.
Файлы находятся в `apps/web/public/achievements/`.
